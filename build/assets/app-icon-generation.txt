Application icon source: build/assets/app-icon.svg
Tray icon source: frontend/src/assets/squirrel-logo.svg
Renderer: scripts/render-app-icons.swift (macOS AppKit; no third-party dependency)

Run from the repository root with:
  swift scripts/render-app-icons.swift

The renderer writes the transparent 1024 x 1024 application PNG to
build/assets/app-icon.png and frontend/public/app-icon.png, the monochrome
alpha tray image to build/assets/tray-icon.png, and a six-size PNG-frame ICO
to build/windows/tamias.ico (16, 32, 48, 64, 128, and 256 px).

The application SVG keeps the existing squirrel paths and adds warm fur tones,
dark edge definition, a light eye, and a gold acorn so the mark reads against
both light and dark Dock backgrounds. It has no background tile; the canvas
and the carved tail channels remain transparent. The macOS build turns the
application PNG into ICNS. Wails uses that colored PNG as the application
icon, while the macOS menu-bar tray keeps the original monochrome template
image so the system can tint it for light and dark menu bars.

The Linux AppImage installs the same application SVG into its private hicolor
scalable/apps theme, named io.tamiops.tami. GTK renders the taskbar window icon
at a small size; passing the 1024 px PNG directly exceeds GTK's X11 icon limit.
The full-size PNG remains the AppImage file/launcher icon. Desktop entry and
GTK application ID use io.tamiops.tami; the X11 window class is Tamias so an
uninstalled AppImage has a readable taskbar label in Cinnamon.

Tray click greeting: build/assets/tray-tail/frame-00.png through frame-19.png.
These 20 transparent 160 x 160 frames rotate only tm-logo-tail around (78,135),
matching the UI's 1050 ms greeting. Regenerate just these frames with:
  swift scripts/render-app-icons.swift --tray-animation-only
Clicks play one greeting and restore the static tray icon; overlapping clicks
share the current playback. App context cancellation stops future updates.
