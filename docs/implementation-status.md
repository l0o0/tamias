# tamiops 功能实施与验收状态

本表以 2026-10-03 的仓库实现为准，对照[产品设计](product-design.md)和[架构说明](architecture.md)。它区分“代码/界面已实现”和“已在目标环境验证”：前者不代表所有服务商、操作系统或第三方客户端均已兼容。

后续迭代已补齐网关写后联动、扫描状态与记录、传输量估算、网关端到端自检、连接编辑、历史版本条件恢复及不完整备份清理。完整边界、后续增强和待验收范围见[剩余功能核对](remaining-work.md)。

## 0.2 实际实现

| 能力 | 代码与界面 | 真实边界 |
| --- | --- | --- |
| 存储连接与文件管理 | WebDAV、S3 和隔离 Demo 连接；连接读写能力探测与配置编辑；文件浏览、上传、下载、建目录、复制、移动、重命名和树删除均接入界面 | 以连接单项能力探测为准；跨存储/多对象操作不是远端事务，部分完成会明确报告 |
| 同步与传输队列 | 双向、仅上传、仅下载、镜像、排除、首次预览、冲突决议、批量删除预览、暂停/取消/重试和持久队列、扫描历史与预计传输量 | 文件级增量；不使用专有块格式。自动本地检测是 2 秒元数据轮询，变化后 900 毫秒防抖再做内容/远端核对；自动远端核对至少每 60 秒一次，或按更长的任务间隔执行 |
| 自动执行规则 | 时间窗、星期、活动网络和仅接通交流电规则接入设置与同步/备份自动调度；手动立即执行绕过自动规则 | 电源状态未知时，“仅接通交流电”规则暂停自动执行；系统环境查询受平台支持范围限制 |
| 读写并发、限速与额度 | 可配置读取并发、全局带宽、单文件、暂存、恢复区和缓存额度；慢下载的网络阶段不占 Core 全局写提交锁 | 读取并发可配置；Core 写提交仍串行，不同对象也可能等待同一提交协调器 |
| 分片上传与下载续传 | S3 multipart 有持久操作记录、分片检查点及恢复；下载检查点带哈希，支持服务端验证过的 Range 续传；能力探测分别核验普通条件写、multipart 条件完成和范围读取 | 仅在对应服务能力探测通过时启用；不支持时使用安全的普通传输路径或拒绝续传，不把 API 存在视为服务端保证 |
| 恢复与未决操作 | 活动核对、接管预览、未知结果核对、恢复预览/独立目录/条件写回和保护性清理接入界面 | 本地恢复区只保存本应用实际保留的副本；第三方绕过本应用的旧内容不能据此恢复。恢复副本完整性会区分已校验和未验证 |
| 备份 | 任务编辑、排除、计划、保留策略、预览、运行、快照列表、恢复到新目录、远端清单恢复及不完整快照清理接入界面 | 不提供跨文件/数据库一致性快照。Demo 远端文件和快照在进程退出后消失；任务历史与本机恢复副本可能仍保留，演示结果不能用作真实备份 |
| 存储迁移 | WebDAV/S3/Demo 之间按实际源/目标能力显示选择；预览冲突、内容核验、保留源、恢复/继续、取消和单独清理预览接入界面 | 真实来源不能迁移到退出即清空的 Demo。复制与删除分步执行；目标成功而源未删除时报告部分完成，不能当成原子 MOVE |
| 按需缓存和文件打开 | 获取、固定、打开编辑、显式检查远端、受保护刷新、冲突写回和缓存恢复区操作接入界面 | 缓存关联 ETag/哈希。刷新会先保护旧干净缓存；被编辑器持有的旧 inode 会移入恢复区，`MutableCache` 不自动清理，以免删除编辑器仍在写入的内容 |
| S3 历史版本 | 有版本能力的连接可列出及读取对象版本，界面支持版本查看、下载到新位置及条件恢复到远端原路径 | 仅适用于服务端版本能力实际可用的连接；远端恢复先绑定当前版本再条件写入；VersionId 也不等价于通用摘要或跨操作事务 |
| WebDAV 网关 | GET/HEAD 范围读取及 If-Range/条件处理；COPY/MOVE 的 Destination、源/目标映射和权限检查；目录 DELETE；LOCK/UNLOCK、锁发现及 PROPFIND 锁属性；访问计数、记录、HTTP 端到端自检及修改后缓存/同步联动均已实现 | 只声明 WebDAV class 1；锁仅支持排他简单令牌，复杂 If 条件与 PROPPATCH 不支持，不能宣称 class 2。普通 S3 MOVE 是复制后删除，失败可能部分完成。远端 WebDAV 缺少原子“仅删空集合”操作时保守拒绝空目录清理，树操作可能留下集合并报告部分完成；内存存储和 S3 零字节目录标记支持各自受保护的空目录删除 |
| 设置、凭据、诊断与统计 | 配置脱敏导入/导出、凭据补录、传输/网关/任务统计、访问记录、自动启动、通知、环境规则、日志及诊断已接入界面 | 应用统计是应用记录到的传输调用和网关请求，包含读取核验流量；不等于协议底层全部 HTTP 请求或服务商账单 |
| CLI 与桌面宿主 | `cmd/tami` 提供 status/export/import/connection-add/credentials/diagnostics/preview/run/serve；可用环境变量提供加密凭据库密钥。`main.go` 提供 Wails 桌面宿主和仅回环的 `-serve` 开发入口 | CLI 复用 Core 和同一数据目录独占锁；`serve` 是单用户 Core/Gateway 宿主，不是团队或多进程服务 |

本轮新增功能及测试范围见[六组功能补齐与验收](feature-completion-test.md)。

## 验证状态与未覆盖范围

- `go test ./...`、`go test -race ./internal/... ./cmd/tami`、`go vet ./...`、`make check`、`make build`、`make cli` 和前端生产构建均已通过；仓库现有 215 个 Go 测试函数。macOS 应用包签名检查通过。解锁后的原生补测另通过整个 Core 包竞态回归，并修复同进程网关连接验证的写锁等待；见[六组功能补测记录](feature-completion-test.md)。
- 细节复查补充了上传中切目录、部分失败汇总、嵌套弹窗与焦点、一次性密码防误关，以及原生同步计数验收，见 [原生交互验收](native-interaction-test.md)。浏览器 UI 已实测同步流程、2 文件备份/恢复且恢复字节一致、2 文件迁移/核验/单独源清理、缓存、自动规则和额度持久化。只读网关实测 PROPFIND 207、GET 200、PUT 403、匿名 GET 401，访问记录正常。配置导出/导入和诊断保存的完整 UI 路径也经 `PickSave` 测试适配验证。
- macOS 已通过原生目录选择、同步、保存面板、默认编辑器打开/编辑/缓存写回、隐藏窗口后网关继续服务、窗口重新打开，以及 WebDAV 连接和钥匙串凭据重启恢复。登录启动参数与创建/移除、第二进程唤起、保存弹窗中退出、通知权限拒绝反馈均已复测；修复详情与紧凑窗口验收范围详见 [原生交互验收](native-interaction-test.md)。通知送达、托盘菜单点击与实际注销登录仍未确认；Windows/Linux CI 配置尚未运行。
- 真实云服务、NAS、S3 兼容厂商、WebDAV 服务及第三方 WebDAV 客户端仍需按产品/版本逐项验收。内存测试服务和协议夹具只能证明代码路径，不代表外部兼容性。
- 本地变化检查目前是元数据轮询，不是文件系统原生递归事件监听；远端轮询频率与任务设置共同决定完整扫描间隔。
- 写提交在 Core 内全局串行；这是当前正确性协调方式，不是已实现的细粒度并行写优化。读取并发另有配置和准入限制。
- 镜像删除、树删除、迁移清理、恢复原路径和 S3 复制后删除都是逐项、带预览/版本条件的流程，不构成多个 Key 的原子事务。
- Demo 是进程生命周期内的隔离演示空间。退出后其远端对象消失；不能将 Demo 中的备份或迁移运行结果当作持久数据。
- 自动变化传播仅按文件处理；专有块级增量、虚拟磁盘/占位文件、多用户团队协作、移动端和统一挂载视图继续是研究/后续候选，不属于本轮完成范围。

本轮使用隔离数据目录和样例文件，覆盖同步、目录操作、网关、恢复、备份、迁移、缓存和取消/续传等流程。真实服务的后续验收应使用用户指定的测试范围；尚未完成的系统或外部服务验证均保留为待验收。
