小花鼠（Tamias）第二个预发布版本，改进 WebDAV 兼容性、同步恢复和桌面交互。

### 更新内容

- 添加或编辑存储连接时自动检测并保存服务能力，减少手动测试步骤。
- 默认按原路径上传和更新同名文件；自动恢复副本默认关闭。严格防覆盖与副本写入可在高级设置中启用。
- 改进非标准 WebDAV 服务的 ETag 和条件请求检测，以及结果待核对操作的恢复，减少同步反复失败。
- 自动跳过 `.DS_Store`，修复 Windows 上父目录时间变化导致的文件监听误报。
- 精简导航、设置和任务操作；新增方向与颜色区分的传输动画、任务自定义图标和帮助入口。
- 使用 Tamias / 小花鼠名称与新图标，修复 macOS 自定义顶栏拖动。
- 自动构建 Windows、macOS 和 Linux 安装包，附带 SHA-256 校验文件。

### 下载与安装

| 系统 | 安装包 |
| --- | --- |
| Windows 10 / 11，x64 | `tamias-0.2.0-beta.2-windows-amd64-setup.exe` |
| macOS 12+，Apple Silicon | `tamias-0.2.0-beta.2-macos-arm64.pkg` |
| macOS 12+，Intel | `tamias-0.2.0-beta.2-macos-amd64.pkg` |
| Linux，x64 | `tamias-0.2.0-beta.2-linux-amd64.AppImage` |

Windows 和 macOS 使用安装向导。Windows 需要 Microsoft Edge WebView2 Runtime；Linux 基于 Ubuntu 24.04 构建，要求 glibc 2.39+、X11 / XWayland 及系统沙箱工具，具体依赖与 AppArmor 配置见 [Linux 使用说明](https://github.com/l0o0/tamias/blob/v0.2.0-beta.2/docs/linux.md)。

```sh
chmod +x tamias-0.2.0-beta.2-linux-amd64.AppImage
./tamias-0.2.0-beta.2-linux-amd64.AppImage
```

每个安装包的 SHA-256 校验值见 `SHA256SUMS.txt`。没有 FUSE 时可添加 `--appimage-extract-and-run` 参数启动。

### 升级与限制

- 更新前请退出旧版本。既有数据目录、应用标识和凭据库保持兼容，无需重新创建同步任务。
- 当前仍为 Beta。Windows 安装器未签名；macOS 安装器未签名或公证，应用使用 ad-hoc 签名。
- 不支持条件请求的服务使用版本预检与写后校验，不能保证阻止其他客户端同时覆盖；删除、移动、备份、迁移及可写网关仍受服务能力限制。
- 同步以文件为单位，备份不提供活动数据库的一致性快照。自动安装与启动检查不能替代完整的人工桌面交互验收。
