首个公开预发布版本，提供 WebDAV / S3 文件管理、文件级增量同步、S3 转 WebDAV 网关、备份恢复、存储迁移和本地缓存。

### 下载

| 系统 | 安装包 |
| --- | --- |
| Windows 10 / 11，x64 | `tamiops-0.2.0-beta.1-windows-amd64-setup.exe`，安装向导 |
| macOS，Apple Silicon | `tamiops-0.2.0-beta.1-macos-arm64.pkg`，安装向导 |
| macOS，Intel | `tamiops-0.2.0-beta.1-macos-amd64.pkg`，安装向导 |
| Linux，x64 | `tamiops-0.2.0-beta.1-linux-amd64.AppImage`，赋予执行权限后启动 |

Windows 安装到当前用户目录，运行需要 Microsoft Edge WebView2 Runtime；缺少运行库时安装向导会引导至微软官方下载页。macOS 安装到 `/Applications`。Linux AppImage 基于 Ubuntu 24.04 构建，包含 GTK / WebKit 运行组件，要求 glibc 2.39 或更新及可用的图形会话、D-Bus 和系统凭据服务。没有 FUSE 时可使用 `--appimage-extract-and-run`。

```sh
chmod +x tamiops-0.2.0-beta.1-linux-amd64.AppImage
./tamiops-0.2.0-beta.1-linux-amd64.AppImage
```

### 本版说明

- 采用 AGPL-3.0-only 许可证；源码由本 Release 对应标签的源代码归档提供，第三方声明随安装包分发。
- Windows、macOS 安装包包含升级所需的稳定应用标识；更新前请从托盘或应用菜单退出旧版本。
- Windows 目录落盘处理适配平台 API；文件内容仍执行同步，目录元数据的断电持久性取决于文件系统。
- macOS 使用融合顶栏与透明松鼠图标。

### 已知限制

- 此版本为 Beta。真实云存储、NAS 及第三方 WebDAV 应用的兼容性需要按实际服务验证。
- Windows 安装器未做 Authenticode 签名；macOS 安装器未做 Developer ID 签名或公证，应用仅有 ad-hoc 签名。系统可能显示未知发布者提示或阻止直接打开。
- 同步以文件为单位；网关不支持完整 PROPPATCH。备份不是活动数据库的应用一致性快照。
- Windows 与 Linux 的自动安装/启动检查不能替代完整的人工桌面交互验收。

每个安装包的 SHA-256 校验值见 `SHA256SUMS.txt`。
