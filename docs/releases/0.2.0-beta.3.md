小花鼠（Tamias）0.2.0-beta.3，新增远端文件夹选择，改进 Linux 输入法支持。

### 更新内容

- 新建和编辑同步任务时，可点击远端文件夹旁的“浏览”，选择根目录或子目录；支持面包屑导航、刷新和错误重试，仍可手动输入路径。
- Linux AppImage 补齐 Fcitx 5 的 GTK 4 输入法模块及依赖，保留桌面会话的输入法设置。
- 输入法组词期间，Escape 和 Tab 交由输入法处理，避免误关闭弹窗或切换焦点。
- 同一 AppImage 已通过 Ubuntu 24.04 和 26.04 的 X11 自动检查，覆盖包内 GTK / Fcitx 模块加载，以及应用与 WebKit 进程启动。

### 下载与安装

| 系统 | 安装包 |
| --- | --- |
| Windows 10 / 11，x64 | `tamias-0.2.0-beta.3-windows-amd64-setup.exe` |
| macOS 12+，Apple Silicon | `tamias-0.2.0-beta.3-macos-arm64.pkg` |
| macOS 12+，Intel | `tamias-0.2.0-beta.3-macos-amd64.pkg` |
| Linux，x64 | `tamias-0.2.0-beta.3-linux-amd64.AppImage` |

Windows 和 macOS 使用安装向导。Windows 需要 Microsoft Edge WebView2 Runtime；Linux 要求 glibc 2.39+、X11 / XWayland 及系统沙箱工具，依赖与 AppArmor 配置见 [Linux 使用说明](https://github.com/l0o0/tamias/blob/v0.2.0-beta.3/docs/linux.md)。

```sh
chmod +x tamias-0.2.0-beta.3-linux-amd64.AppImage
./tamias-0.2.0-beta.3-linux-amd64.AppImage
```

每个安装包的 SHA-256 校验值见 `SHA256SUMS.txt`。没有 FUSE 时可添加 `--appimage-extract-and-run` 参数启动。

### 升级与验证范围

- 更新前请退出旧版本，已有连接和同步任务无需重新配置。
- 当前仍为 Beta。Windows 安装器未签名；macOS 安装器未签名或公证，应用使用 ad-hoc 签名。
- Linux 自动检查使用虚拟 X11 环境，未启动 Cinnamon 或真实 Fcitx 输入法进程；候选框、输入法切换和中文上屏仍需实机确认。
