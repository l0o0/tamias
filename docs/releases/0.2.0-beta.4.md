小花鼠（Tamias）0.2.0-beta.4，修复 Linux 任务栏的应用名称和图标。

### 更新内容

- Linux 窗口标识改为 Tamias，避免任务栏将应用显示为 Wails；窗口标题保留“小花鼠”。
- Linux 任务栏使用透明背景的棕色小花鼠图标，修复 GTK 4 未设置窗口图标及高分辨率图标被 X11 丢弃的问题。
- 统一 AppImage 桌面文件与窗口标识，并增加运行中窗口名称、图标颜色及透明背景的自动检查。

### 下载与安装

| 系统 | 安装包 |
| --- | --- |
| Windows 10 / 11，x64 | `tamias-0.2.0-beta.4-windows-amd64-setup.exe` |
| macOS 12+，Apple Silicon | `tamias-0.2.0-beta.4-macos-arm64.pkg` |
| macOS 12+，Intel | `tamias-0.2.0-beta.4-macos-amd64.pkg` |
| Linux，x64 | `tamias-0.2.0-beta.4-linux-amd64.AppImage` |

Windows 和 macOS 使用安装向导。Windows 需要 Microsoft Edge WebView2 Runtime；Linux 要求 glibc 2.39+、X11 / XWayland 及系统沙箱工具，依赖与 AppArmor 配置见 [Linux 使用说明](https://github.com/l0o0/tamias/blob/v0.2.0-beta.4/docs/linux.md)。

```sh
chmod +x tamias-0.2.0-beta.4-linux-amd64.AppImage
./tamias-0.2.0-beta.4-linux-amd64.AppImage
```

每个安装包的 SHA-256 校验值见 `SHA256SUMS.txt`。没有 FUSE 时可添加 `--appimage-extract-and-run` 参数启动。

### 升级与验证范围

- 更新前请退出旧版本，已有连接和同步任务无需重新配置。
- 当前仍为 Beta。Windows 安装器未签名；macOS 安装器未签名或公证，应用使用 ad-hoc 签名。
- Linux 图标修复已通过 Ubuntu 24.04 与 26.04 的 X11 自动检查，实际窗口导出了 Tamias 标识和透明底棕色图标。测试使用 Xvfb，未启动完整 Cinnamon 桌面；任务栏悬停和分组仍需实机确认。
